# 99_작업중

초안·실험용. 여기 있는 건 **아직 쓸 수 있는 상태가 아니다**라는 뜻.

## 만들어진 곳을 따라 갈린다

```
99_작업중/
├── 이미지/     ← 뷰어의 이미지 → 조립 에서 저장한 것
└── 챗봇/       ← 뷰어의 챗봇 → 작성 에서 저장한 것
```

저장소의 다른 폴더와 같은 규칙이다 (`00_`~`05_` 전부 `챗봇/` `이미지/` 로 갈린다).
뷰어는 이 두 폴더에만 쓴다. 그래서 초안이 어느 파이프라인의 것인지 경로만 봐도 안다.

## 뷰어에서 다루기

읽기 탭에는 나오지 않는다. 초안은 **만들어진 그룹의 `작업중` 탭**에서 본다.

| 그룹 | 탭 | 보는 것 |
|---|---|---|
| 이미지 | 작업중 | `99_작업중/이미지/` |
| 챗봇 | 작업중 | `99_작업중/챗봇/` |

거기서 바로 **수정·삭제**할 수 있다 (`node viewer/serve.mjs` 로 띄웠을 때).
