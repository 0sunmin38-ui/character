> `[작업]` **이 폴더에서 만든 문서: 원문에 없는 규칙·판단 포함 · 고쳐도 됨**
# luvheilassistant: AI 캐릭터 이미지 프롬프트 작업 폴더

**목적:** AI 기반 캐릭터 채팅 플랫폼에 올릴 캐릭터의
**이미지(일러스트) 프롬프트**를 제작·보관한다.

> **캐릭터(챗봇) 프롬프트는 여기 없다.** 별도 저장소 **`luvheilcharacter`** 로 떨어져 나갔다.
> 이미지는 혼자 태그를 골라 조립하고, 캐릭터는 Claude 와 주고받으며 짠다. 성격이 다르다.
> 그리고 이 저장소는 작가 견본이 36MB 라 캐릭터 쪽이 끌고 다닐 이유가 없다.

---

## 먼저: 원문과 정리물 구분

모든 `.md` 첫 줄에 등급 배너가 있다.

| 배너 | 뜻 | 편집 |
|---|---|---|
| `[원문]` | 외부 글 전재. 남의 글 | ❌ |
| `[정리]` | 원문에서 뽑아 재배치. 값은 원문 것 | △ |
| `[작업]` | 원문에 없는 규칙·판단. 우리가 만든 것 | ⭕ |

**등급은 폴더가 아니라 배너로 판단한다.** `00_가이드/` 안에도 `[원문]` 과 `[정리]` 가 섞여 있다.
파일별 등급과 읽는 순서는 → **`문서구분표.md`**

## 폴더 지도

| 폴더 | 성격 | 내용 |
|---|---|---|
| `00_가이드/` | **읽는 것** | 방법론·참고 문서(서술형 md). 원문은 수정하지 않음 |
| `01_자료/` | **찾는 것** | 태그·링크 CSV. `.md` 는 두지 않음 |
| `02_템플릿/` | 빈 양식 | 채워 넣을 틀. 복사해서 씀 |
| `03_프롬프트/` | **★ 산출물** | 완성된 프롬프트. 종류별로 분류 |
| `04_생성기/` | 도구 | AI에게 시킬 메타 프롬프트 (Gems 대체) |
| `05_검토/` | 도구 | 완성 초안을 점검하는 검토표 |
| `99_작업중/` | 임시 | 초안·실험. 정리되면 03으로 승격 |
| `dcgall/` | 수집기 | 디시 AI채팅 갤러리 크롤러. 새 프롬프트/노하우 자동 수집 |
| `문서구분표.md` | 색인 | **원문 / 정리 / 작업 구분 + 읽는 순서** |

```
luvheilassistant/
├── 00_가이드/이미지/    01 작가태그 · 02-1 스타일 · 02-2 퀄리티·부정 · 03 컨셉→프롬프트
│                      · 04 NAI팁 설정과문법 · 05 NAI팁 프롬프팅과기능
├── 01_자료/이미지/      0-참고링크(19) · 1-태그사전(4,205) · 1-스타일태그(88)
│                      · 1-작가태그(248) · 작가샘플/ (견본 180장)
├── 02_템플릿/이미지/     26슬롯 기본출력 · 작가태그출력 · 캐릭터 외형고정
├── 03_프롬프트/이미지/   ← 최종 산출물
│   ├── 작가태그/         그림체 결정
│   ├── 스타일프리셋/      퀄리티 / 부정 프롬프트 세트
│   ├── 캐릭터/           캐릭터별 외형 고정 태그
│   └── 장면/             상황·컨셉별 프롬프트
├── 04_생성기/
├── 05_검토/            초안 점검 체크리스트
├── 99_작업중/이미지/     뷰어 이미지→조립 에서 저장한 초안
├── viewer/             에셋 화면 (node viewer/serve.mjs)
└── dcgall/             디시 AI채팅 갤러리 크롤러 (수집 도구)
```

`dcgall/` 은 **프롬프트 파이프라인 밖의 소프트웨어**라 `00_`~`05_` 번호를 붙이지 않았다.

## 작업 흐름

### 이미지 프롬프트
```
작가 태그 (그림체 결정)              → 03_프롬프트/이미지/작가태그/
  + 캐릭터 외형 고정 태그              → 03_프롬프트/이미지/캐릭터/
  + 26슬롯 기본 태그 (컨셉·장면)        → 03_프롬프트/이미지/장면/
  + 퀄리티 프롬프트 · 부정 프롬프트      → 03_프롬프트/이미지/스타일프리셋/
```
캐릭터 프로필이 이미 있다면(`luvheilcharacter`) → Gem(Nai 프롬프트 생성)에 첨부해 외형 고정 태그를 뽑는다.
양식은 `02_템플릿/이미지/03_캐릭터_외형고정_템플릿.md`.
같은 캐릭터의 캐릭터 폴더명과 이미지 파일명은 **같은 이름**으로 맞춘다.

## 규칙

- **`[원문]` 배너가 붙은 파일은 수정하지 않는다.** (전부 `00_가이드/` 안에 있다)
  추출·가공한 결과는 `02_`~`05_`에 새로 만든다.
- **같은 내용을 두 곳에 적지 않는다.** 정본을 정하고 다른 쪽에는 포인터만:
  주제별 정본표는 `00_가이드/README.md`, 부정/퀄리티 프롬프트는 `03_프롬프트/이미지/스타일프리셋/`.
- **템플릿에는 구조만, 태그 값은 CSV에.** 태그 목록이 `02_템플릿/`에 쌓이면 `01_자료/`로 옮긴다.
- 완성 프롬프트는 반드시 **복붙 가능한 코드블록** 형태로 저장한다.
- 한 프롬프트 안에서 **형식(Markdown/YAML/XML)과 언어(한/영/중)를 섞지 않는다.**
- 캐릭터 이름은 `luvheilcharacter` 쪽과 동일하게 쓴다.
- 프롬프트 파일 맨 위에 **대상 플랫폼 · 언어 · 글자수/토큰**을 적어둔다.

## dcgall: 수집기

디시인사이드 AI채팅 마이너 갤러리에서 개념글·검색 결과를 긁어 `dcgall/data/` 에 쌓고
`dcgall/out/index.html` 로 리포트를 만든다. 새 퀄리티/부정 프롬프트, 지침 노하우를 찾는 용도.

```bash
node dcgall/crawl.mjs daily     # 전체글 5p + 개념글 3p
node dcgall/crawl.mjs sweep     # 개념글 15p 깊게
node dcgall/crawl.mjs watch     # 키워드 감시 (프롬프트 / 지침 / 제타)
node dcgall/report.mjs          # out/index.html 생성
```

수집물에서 건진 것은 **그대로 두지 말고** 해당 위치로 옮긴다.
- 새 퀄리티/부정 프롬프트 → `03_프롬프트/이미지/스타일프리셋/` 에 `Q7`, `N8`… 로 추가
- 새 작가 태그 조합 → `03_프롬프트/이미지/작가태그/`
- 챗봇 지침 노하우 → **`luvheilcharacter`** 저장소로
- 참고할 원문 링크 → `01_자료/이미지/0-참고링크.csv`
