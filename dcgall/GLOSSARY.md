# AI채팅 마이너 갤러리 은어 사전

`dcgall/glossary.json` 에서 자동 생성. 이 갤러리 글을 읽거나 분류할 때의 문맥 기준이다.

## 개념 묶음

플랫폼마다 이름만 다른 같은 개념. 분류기는 이 묶음 단위로 판단한다.

- **상태창 계열** (`statusboard`) — 캐릭터챗 매턴의 변화를 기록해 보여주는 UI. 개념은 '상태창'이고 이를 html 등으로 구현한 게 위젯·트래커. 플랫폼마다 부르는 이름이 다르다.
  - 표면형: `상태창`, `위젯`, `트래커`
- **유저 캐릭터** (`pc`) — NPC와 롤플레이를 진행하기 위한 사용자 쪽 캐릭터. {{user}} 로 지칭된다.
  - 표면형: `페소`
- **제작된 캐릭터** (`npc`) — 플랫폼에 올라온, 유저가 상대하는 캐릭터
  - 표면형: `캐`
- **캐릭터 이미지** (`asset`) — 캐릭터에 붙는 이미지 리소스
  - 표면형: `에셋`
- **OOC** (`ooc`) — 진행 상황과 무관한 상황을 상정해 캐릭터 반응을 유도하는 번외 롤플레이
  - 표면형: `ooc`
- **지침** (`guideline`) — 출력을 조정하기 위해 제작 프롬프트나 유저노트에 넣는 지시문
  - 표면형: `지침`, `문체지침`, `출력량`, `유저노트`
- **그림체 고정** (`artstyle`) — 작가태그·프롬프트를 깎아 그림체를 고정하는 작업과 그 결과물
  - 표면형: `그깎`, `작태`, `그림체`
- **외부 도구** (`extension`) — 플랫폼을 보조하는 확장프로그램·북마클릿·스크립트
  - 표면형: `확프`

## 조어 규칙

- **Gemini** — 젬 + 숫자 읽기 = Gemini 버전 (젬이오=2.5, 젬삼일=3.1, 젬삼칠플=3.7 Flash)  `/젬\s?(이오|삼칠플|삼칠|삼일|삼|\d+(\.\d+)?)/`
- **Claude Opus** — 숫자 + 푸스 = Opus 버전 (5푸스=Opus 5, 47푸스=Opus 4.7)  `/(\d{1,2})?푸스/`
- **Claude Sonnet** — 소넷 + 버전  `/소넷\s?\d+(\.\d+)?/`
- **NovelAI** — 이미지 생성 모델 버전 표기  `/(nai|노벨\s?ai)\s?v?\d(\.\d)?/`
- **플랫폼 + 모델 합성어** — 플랫폼 약칭 뒤에 모델 약칭을 붙여 부르는 말이에요. 롶푸스는 로판AI의 Opus, 케푸스는 케덕의 Opus  `/(롶|케|팊|팟|움)(푸스|삼칠플|삼칠|이오|넷)/`
