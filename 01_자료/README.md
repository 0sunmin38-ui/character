# 01_자료: 찾아 쓰는 데이터

**여기는 CSV만 둔다.** 읽는 글(서술형 문서)은 전부 `00_가이드/` 로 간다.

> 구분 기준: **읽는 것이면 `00_가이드/`, 검색해서 값을 꺼내는 것이면 `01_자료/`.**
> 그래서 이 폴더에 `.md` 는 이 README 하나뿐이다.

> **캐릭터(챗봇) 프롬프트는 여기 없다.** 별도 저장소 `luvheilcharacter` 로 떨어져 나갔다.

```
01_자료/
└── 이미지/
    ├── 0-참고링크.csv      태그·작가태그·정보글·도구 링크 19건
    ├── 1-태그사전.csv     4,205행  NovelAI 태그
    ├── 1-스타일태그.csv      88행  매체·아트스타일·색상·특수효과
    └── 1-작가태그.csv       140개  Notion 작가 태그
```

**`0-`** 은 링크(어디서 더 찾을지) · **`1-`** 은 태그 데이터. 같은 층이면 같은 번호를 쓴다.
새 태그를 찾으면 **파일을 만들지 말고 해당 CSV에 행을 추가**한다.

## 쓰는 법

```bash
D=01_자료/이미지
grep -i "안경"            $D/1-태그사전.csv     # 한글명·태그 전체 검색
awk -F, '$1=="태그의상"'   $D/1-태그사전.csv     # 의상 태그만
awk -F, '$6!="TRUE"'      $D/1-태그사전.csv     # 전체 이용가만
grep -i "watercolor"      $D/1-스타일태그.csv
```

- AI에 첨부할 때는 `시트`/`분류` 컬럼으로 필요한 것만 잘라서 넣는다 (태그사전 통째로는 300KB).
- **태그에 언더바(`_`)가 있으면 쓸 때 띄어쓰기로 바꾼다.** (원본 시트 주의사항)
