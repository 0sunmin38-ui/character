# 작가샘플

작가 태그마다 **그 태그로 뽑은 견본 그림**을 둔다.
140개를 글자만 보고 고를 수는 없다 — 그림체는 눈으로 고르는 것이다.

뷰어의 **에셋 → 사전 → 작가** 표가 이 폴더를 읽어 태그 옆에 붙인다.

## 파일 이름

```
<태그슬러그>_남.webp
<태그슬러그>_여.webp
```

슬러그는 태그에서 `artist:` 를 떼고 소문자로 바꾼 뒤, 영문·숫자·한글이 아닌 것을 `-` 로 묶은 것이다.

| 태그 | 남캐 견본 | 여캐 견본 |
|---|---|---|
| `artist: ishikawa hideki` | `ishikawa-hideki_남.webp` | `ishikawa-hideki_여.webp` |
| `artist:0820_lakia` | `0820-lakia_남.webp` | `0820-lakia_여.webp` |

`_남` 대신 `_m` `_male`, `_여` 대신 `_f` `_female` 도 받는다.
확장자는 `webp` `png` `jpg` `gif` `avif`.

**표의 빈 칸에 그림을 끌어다 놓으면 이름을 알아서 붙여 여기 저장한다.**
표가 비어 있는 칸에 기대하는 파일명을 적어두므로 직접 넣어도 된다.

용량이 커지므로 **webp 를 권한다.** 원본 PNG 를 그대로 쌓으면 저장소가 금방 무거워진다.
