## A. 형식 검사

| # | 항목 | 판정 기준 | 위반 시 |
|---|---|---|---|
| A1 | 형식 통일 | 한 프롬프트 칸 안에 Markdown/YAML/XML/INI가 섞이지 않았는가 | 하나로 통일. Claude 계열이면 XML 유리 |
| A2 | 언어 통일 | 한 칸 안에 한/영/중이 섞이지 않았는가 | 플랫폼이 토큰제면 영어, 글자수제면 한국어로 통일 |

## B. 구조 검사: 하네스 8블록

블록마다 **있는가 / 형태가 맞는가**를 따로 본다. 있어도 형태가 틀리면 없는 것과 비슷하다.

### ② Anchor: 최상단 고정
- [ ] 프롬프트 **맨 위**에 있는가 (순서가 곧 우선순위)
- [ ] **3줄 이내**인가
- [ ] 여기 적힌 게 전부 "이 캐릭터를 이 캐릭터답게 만드는 것"인가
  - 나이·키·소속 같은 **사실 정보는 앵커가 아니다** → `[기본 정보]`로 내린다
  - 판정법: 그 줄을 지웠을 때 **다른 캐릭터가 되는가?** 아니면 앵커가 아니다

### ① Block: 서랍 나누기
- [ ] 역할별로 구역이 나뉘어 있는가 (기본 정보 / 성격·말투 / 행동 규칙 / 상황별 반응 …)
- [ ] 같은 정보가 **두 블록에 중복**되어 있지 않은가
- [ ] 한 블록 안에 성격이 다른 정보가 섞여 있지 않은가

### ③ Trigger: 조건 → 반응
- [ ] **`조건 → 반응`** 형태인가 (서술문으로 풀어 쓴 건 트리거가 아니다)
- [ ] 최소 **5개** 이상인가
- [ ] 형용사 한 줄로 때운 항목이 없는가
  - ✗ `냉소적이다` → AI가 매번 다르게 해석
  - ○ `{{user}}가 도발하면 → 냉소적으로 반응하되 적대적으로 굴지는 않음`
- [ ] 트리거끼리 **모순**되지 않는가

### ④ Guard: 어떤 상황에서도 안 하는 것
- [ ] 금지가 **부정문으로 명확한가** ("~하지 않는다")
- [ ] Guard와 Trigger가 **충돌하지 않는가** (Guard가 항상 이긴다)
- [ ] 캐릭터가 유저 유도에 휩쓸릴 지점이 막혀 있는가

### ⑤ Fallback: 조건이 없을 때
- [ ] 기본 어조가 정해져 있는가
- [ ] 기본 답변 길이가 정해져 있는가
- [ ] **먼저 하지 않는 것**이 적혀 있는가
> 없으면 AI는 "친절한 게 맞겠지" 쪽으로 수렴한다. 캐릭터가 물러지는 가장 흔한 원인.

### ⑥ Scope: 아는 것 / 모르는 것
- [ ] 캐릭터가 **모르는 것**이 명시돼 있는가 (유저의 과거, 미공개 설정 등)
- [ ] 세계관 **외부 정보**(현실 세계, 타 작품) 인식 차단이 있는가

### ⑦ Chain: 관계 단계
- [ ] 첫 대화 / 중간 / 신뢰 이후의 **행동 차이**가 적혀 있는가
- [ ] 단계 전환 조건이 있는가 (막연한 "친해지면" 금지)

### ⑧ Layer: 캐릭터 영역 / 메타 영역
- [ ] 출력 규칙이 캐릭터 대사 영역과 **분리**돼 있는가
- [ ] 규칙 영역 내용이 대사에 새어나오지 않도록 명시했는가

## C. 밀도 검사

컨텍스트는 **수확 체감이 있는 유한 자원**이다. 길수록 좋아지지 않고, 어느 지점부터
캐릭터 일관성이 오히려 무너진다. 아래는 그 근거로 하는 판단이다.

### C1. 고도(altitude): 두 극단 사이인가

| 극단 | 증상 | 조치 |
|---|---|---|
| 너무 낮음 | 대사를 통째로 지정, if-else식 하드코딩 | 원칙으로 올림 |
| 너무 높음 | 형용사만 나열 (`다정하다`, `쿨하다`) | 트리거로 내림 |

### C2. 고신호 최소 집합
각 줄에 대해: **이 줄을 지우면 캐릭터가 달라지는가?**
- 아니오 → 삭제 후보
- 판단 유보 → 로어북 후보 (C3)

### C3. 로어북으로 뺄 것
상시 필요 없는 설정은 프롬프트에서 빼고 `02_템플릿/챗봇/06_로어북_템플릿.md`로 옮긴다.
필요할 때만 불러오는 것이 원칙과 맞다.

| 프롬프트에 상주 | 로어북으로 |
|---|---|
| 정체성, 말투, 행동 규칙, 관계 | 지명·조직·역사, 조연 인물, 특정 사건, 용어 설명 |

### C4. 중복 제거
- 같은 지시가 여러 블록에 반복되는가
- 프로필(자료)에만 있으면 되는 정보가 프롬프트에 들어와 있는가
  → 프로필·세계관은 **자료**, 프롬프트 칸에 들어가는 건 재배치 결과물

---

### C5. 그래도 넘칠 때 (줄이는 순서)
글자수·토큰 제한을 넘겼는데 C1~C4 로도 안 줄면 이 순서로 버린다.

1. 조연·용어·이벤트 상세 → **로어북**으로 이동 (메인에는 이름·소속만)
2. `# 세계관 핵심`, `# 톤 & 분위기` 등 간접적인 섹션 삭제
3. `# NSFW` (전체 이용가면 무조건 삭제)
4. `# 일과`: 실제로 대화에 안 쓰이면 축약
5. 줄글로 남은 문장 → `속성: 값` 으로 재압축


## 검토 결과 서식

```
■ 형식     A1 O / A2 X(한영 혼용 3곳) / A3 O / A4 X / A5 X / A6 O
■ 구조     Anchor △(5줄, 사실정보 포함) · Trigger X(3개, 2개는 형용사)
           Fallback 없음 · Scope 없음 · 나머지 O
■ 밀도     삭제 후보 n줄 / 로어북 이관 n항목 / 중복 n곳

▶ 우선순위
1. (치명) …
2. (중요) …
3. (선택) …
```

우선순위 기준: **치명**: 캐릭터가 무너지는 원인 (Anchor·Guard·Fallback 결손, 형식/언어 혼용) ·
**중요**: 일관성이 흔들리는 원인 (Trigger 부족, 중복) · **선택**: 토큰 절약, 표기 정리

## 자주 나오는 실패

| 증상 | 대개 이 블록 문제 |
|---|---|
| 대화가 길어지면 캐릭터가 흐릿해짐 | Anchor가 없거나 최상단이 아님 |
| 점점 착해지고 물러짐 | Fallback 부재, Guard 부족 |
| 같은 상황에서 반응이 매번 다름 | Trigger가 형용사로만 되어 있음 |
| 설정에 없는 걸 지어냄 | Scope 부재 |
| 메타 발언이 대사에 섞임 | Layer 미분리, `OOC` 표기 사용 |
| 엉뚱한 언어로 답함 | 언어 혼용 (A2) |
