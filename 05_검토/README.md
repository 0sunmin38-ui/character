## 쓰는 법

1. 초안을 `99_작업중/`에 둔다
2. 해당 검토표 순서대로 본다 — **앞 단계를 고치지 않고 뒤로 가지 않는다**
3. 결과를 검토표 하단 서식으로 정리하고, 우선순위대로 수정
4. 통과하면 `03_프롬프트/`로 승격
