# 05_검토: 가져온 초안을 판정하는 잣대

**생성은 여기서 하지 않는다.** 초안은 뷰어나 Gem 으로 만들고,
이 폴더는 그 결과물을 **고칠 지점을 찾는 데** 쓴다.

> **캐릭터(챗봇) 프롬프트는 여기 없다.** 별도 저장소 `luvheilcharacter` 로 떨어져 나갔다.
> 챗봇 검토표(`01`)는 그쪽으로 옮겼다. 번호는 그대로 두었다.

| 파일 | 대상 |
|---|---|
| `02_이미지프롬프트_검토표.md` | 이미지 프롬프트: 태그 사전 대조가 중심 |

## 쓰는 법

1. 초안을 `99_작업중/`에 둔다
2. 해당 검토표 순서대로 본다. **앞 단계를 고치지 않고 뒤로 가지 않는다**
3. 결과를 검토표 하단 서식으로 정리하고, 우선순위대로 수정
4. 통과하면 `03_프롬프트/`로 승격
