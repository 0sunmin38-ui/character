# 이미지 프롬프트 검토표

챗봇 쪽과 달리 **상당 부분이 기계적으로 판정된다.** 태그가 실재하는지는 사람이나 AI가
판단하면 틀린다. 사전 대조가 정확하다.

근거: `01_자료/이미지/1-태그사전.csv` (4,187행) · `01_자료/이미지/` (140개) ·
`00_가이드/이미지/04_NAI팁_설정과문법.md` · `02_템플릿/이미지/`

## A. 태그 검증 (사전 대조)

| # | 항목 | 판정 기준 |
|---|---|---|
| A1 | 실재하는 태그인가 | `01_자료/이미지/1-태그사전.csv` 의 `태그` 컬럼에 있는가. **없으면 AI가 지어낸 것** |
| A2 | 언더바 변환 | `_`가 남아 있지 않은가 → 띄어쓰기로 (원본 시트 주의사항) |
| A3 | NSFW 플래그 | 의도치 않은 NSFW 태그가 섞이지 않았는가 (`NSFW=TRUE` 467행 · 공란 436행은 원본에 값 없음) |
| A4 | 작가 태그 표기 | `artist:` 접두사가 있는가. 괄호 이름은 통째로 쓰는가 → `artist: alexi (tits!)` |

## B. 문법 검사

| # | 항목 | 판정 기준 | 위반 시 |
|---|---|---|---|
| B1 | 가중치 표기 | `숫자::태그::` 형식인가 | `{}`, `[]` 사용 금지 |
| B2 | 숫자 끝 태그 | 숫자로 끝나는 태그 뒤에 공백이 있는가 | `1.2::1girl ::` |
| B3 | 음수 가중치 | 제거(`-1::hat::`)와 반전(`-1::monochrome::`) 의도가 맞는가 | 반전은 결과가 뒤집힌다 |
| B4 | 괄호 짝 | `::` 짝이 맞는가 | 안 맞으면 통째로 무시됨 |

## C. 구조 검사

- [ ] 태그 배치 순서가 **26슬롯 정본**과 맞는가: `02_템플릿/이미지/01_기본출력_구조_템플릿.md`
      (작가태그 → 캐릭터 외형고정 → 00~26 슬롯 → 퀄리티 → 부정)
      > 배치 순서는 출처마다 다르다. 디시 정리본 §3(`[Frame]→[Creator]→[Setting]→[Style]`)과
      > `00_가이드/이미지/05_NAI팁_프롬프팅과기능.md` §2 권장 순서는 **참고값**이며, 판정은 26슬롯 기준으로 한다.
- [ ] 작가 태그·스타일 태그에 `(medium)` 또는 `::` 구분이 붙었는가
      (`ink` 같은 태그는 사물 잉크로 해석될 수 있음)
- [ ] 캐릭터 외형 고정 태그가 별도 블록으로 분리돼 있는가
- [ ] 퀄리티/부정 프롬프트가 `03_프롬프트/이미지/스타일프리셋/`의 세트를 쓰는가
      (매번 새로 쓰면 결과가 흔들린다)
