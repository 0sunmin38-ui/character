> `[작업]` **이 폴더에서 만든 문서 — 고쳐도 됨**
# viewer — 작업 뷰어

저장소를 브라우저에서 읽고, 태그를 골라 조립하고, 검토표 A·B절을 기계로 판정한다.
**단일 HTML · 빌드 없음 · 외부 의존 없음.**

## 여는 법

저장소 **루트에서** 서버를 띄운다. `viewer/` 안에서 띄우면 안 된다.

```bash
node viewer/serve.mjs 8799      # 저장 기능까지 (권장)
python3 -m http.server 8799     # 읽기만 — 저장 버튼은 내려받기로 대체된다
```
→ http://localhost:8799/viewer/

`serve.mjs` 는 의존성이 없다. 정적 서빙 + `POST /_save` 하나뿐이고,
**쓰기는 `99_작업중/` 안의 `.md` 로만** 허용한다 (`/` `..` 포함 이름·80자 초과·경로 탈출은 거부).

Codespaces에서는 포트가 자동 포워딩된다. VS Code의 Simple Browser 로 열면 터미널 옆에 붙는다.

> `file://` 로 열면 동작하지 않는다. CSV·MD 를 `fetch` 로 읽기 때문이다.

## 탭

**`읽기` `이미지` `챗봇` 세 그룹**이 상단에 있고, 그룹을 누르면 하위 탭이 열리면서 첫 항목이 선택된다.

| 그룹 | 하위 | 하는 일 |
|---|---|---|
| **읽기** | — | md 렌더링 + 복사. 사이드바 점 색 = 배너 등급 (초록 원문 · 파랑 정리 · 노랑 작업) |
| **이미지** | 태그 | 태그사전 4,205 · 스타일태그 88 · 작가태그 140 · 참고링크 검색. 누르면 담긴다 |
| | 조립 | 담은 태그를 26슬롯에 배치 → 작가태그 + Q + N 붙여 완성 프롬프트 복사 |
| | 검토 | `05_검토/02` 의 A1·A2·A3·B2·B4 판정 |
| **챗봇** | 작성 | 하네스 8블록 폼을 채우면 프롬프트로 조립 · 글자수 실시간 집계 |
| | 검토 | `05_검토/01` 의 A절(형식)·B절(블록 유무) 판정 |

담은 태그와 챗봇 작성 내용은 `localStorage` 에 남아 새로고침해도 유지된다.

## 파일 목록을 찾는 방법

1. `viewer/manifest.json` 이 있으면 그걸 쓴다 — **정적 호스팅(GitHub Pages)용**
2. 없으면 서버의 디렉터리 목록을 훑는다 — 로컬 서버용

목록은 부팅 때 한 번 읽는다.
- **저장하면** 그 파일이 목록에 바로 추가된다
- **터미널에서 파일을 만들었다면** 상단 `↻`
- **manifest 를 쓰는 중이라면** 파일을 추가한 뒤 다시 만들어 커밋해야 반영된다

```bash
node viewer/build-manifest.mjs
```

## GitHub Pages 로 링크 만들기

저장소가 **공개**여야 무료 Pages 를 쓸 수 있다.

```bash
node viewer/build-manifest.mjs && git add -A && git commit -m "manifest" && git push
```

저장소 → Settings → Pages → Source `Deploy from a branch` → `main` / `/ (root)`
→ `https://0sunmin38-ui.github.io/character/viewer/`

정적 호스팅에서는 **저장 기능이 자동으로 숨겨진다** (쓰기 엔드포인트가 없다).
읽기·검색·조립·검토는 전부 동작한다.

## 담은 태그 패널

**이미지 그룹에서만 나온다.** 26슬롯 조립용이라 읽기·챗봇에서는 자리만 차지한다.
그룹을 따라 자동으로 나타나고 사라지므로 별도 토글 버튼은 두지 않았다.
이미지 그룹 안에서 경계선을 더블클릭해 접어두면 그 설정은 기억한다
(접힌 상태에서도 경계선 드래그로 되돌릴 수 있다).

## 저장

**조립**과 **작성** 탭에 이름 칸과 `99_작업중에 저장` 버튼이 있다.
`99_작업중/<이름>.md` 로 저장되고, 같은 이름이 있으면 덮어쓸지 묻는다.
입력한 이름도 기억한다.

저장되는 파일에는 `03_프롬프트/README.md` 의 **파일 머리말**(플랫폼·언어·형식·글자수·최종 수정)이
자동으로 붙는다. 승격할 때 그대로 쓰면 된다.

> `python3 -m http.server` 로 열었다면 쓰기 엔드포인트가 없어 **내려받기로 대체**된다.

## 입력 중 기호 변환

저장소 표기 규칙(`→` `·`)에 맞춰 챗봇 작성 탭에서 타이핑하는 즉시 바꾼다.

| 입력 | 결과 | | 입력 | 결과 |
|---|---|---|---|---|
| `->` | `→` | | `...` | `…` |
| `<-` | `←` | | `!=` | `≠` |
| `=>` | `⇒` | | `>=` `<=` | `≥` `≤` |

`조건 -> 반응` 을 그대로 치면 `조건 → 반응` 이 된다. 검토 탭의 Trigger 개수도 `→` 로 세므로
바꿔 두는 편이 유리하다. 백스페이스로 지울 때는 변환하지 않는다.

## 패널

- **너비** — 패널 사이 경계선을 드래그. **150~560px**
- **접기** — 경계선 더블클릭, 또는 우측 상단 `◧` (파일 목록)
- **폴더** — 사이드바의 폴더 이름을 누르면 접힌다

접힘 상태·너비·폴더 접힘은 전부 저장된다.

### 좁아지면 줄어든다

글자가 깨지지 않도록 폭에 따라 3단계로 바꾼다. `ResizeObserver` 로 실제 폭을 재서
`data-w` 를 붙이므로 드래그하는 동안에도 즉시 반응한다.

| | lg | md | sm |
|---|---|---|---|
| **헤더** (기준) | ≥760 | ≥560 | <560 |
| 그룹 탭 | 읽기 이미지 챗봇 | 그대로 | 📖 🖼 💬 |
| 파일·태그 수 | 보임 | 숨김 | 숨김 |
| 로고 | 보임 | 보임 | 숨김 |
| **본문 표** (기준) | ≥620 | ≥440 | <440 |
| 분류 · 비고 · 용도 | 보임 | 숨김 | 숨김 |
| 시트 · 섹션 | 보임 | 보임 | 숨김 |
| 한글명 · 태그 | 보임 | 보임 | 보임 |
| 담은 태그 (기준) | ≥230 | ≥165 | <165 |
| 제목 | 담은 태그 | 태그 | 태 |
| 비우기 버튼 | 글자 | ✕ | ✕ |
| 슬롯 드롭다운 | 88px | 60px | 숨김 |
| 파일 목록 (기준) | ≥210 | ≥170 | <170 |
| 폴더 파일 개수 | 보임 | 보임 | 숨김 |

## 읽기 탭의 복사

| 버튼 | 쓰는 곳 |
|---|---|
| **본문 복사** | 배너 줄을 뺀 문서 전체. 프로필·세계관 템플릿을 Gem 에 붙여넣을 때 |
| 코드블록에 마우스를 올리면 뜨는 **복사** | 블록 하나만. 프리셋 `Q3` 하나, 하네스 블록 하나 |
| **경로** | 터미널에서 파일을 지정할 때. 한글 경로를 타이핑하지 않으려는 용도 |

프리셋처럼 블록이 여러 개인 문서는 **필요한 블록 하나만** 복사하면 된다.
`01_캐릭터_프로필_템플릿.md` 처럼 코드블록이 없는 문서는 본문 복사를 쓴다.

## 글자수 세기 (챗봇 작성 탭)

입력하는 즉시 집계한다.

- **블록마다** 라벨 오른쪽에 글자수 — 어느 블록을 줄일지 바로 보인다
- **상단 요약** — 글자수 · 공백 제외 · 한글 · 토큰 추정
- **제한** 칸에 숫자를 넣으면 게이지와 남은 글자수가 뜬다.
  85%를 넘으면 주황, 초과하면 빨강으로 바뀌고 초과분을 표시한다. 입력한 제한값은 저장된다

> 플랫폼별 제한 수치는 저장소에 자료가 없어 직접 넣는다.
> 토큰 추정은 한글 1.4 · 그 외 0.3 으로 잡은 **어림값**이다. 실제 토크나이저와 다르다.
> 토큰제 플랫폼이면 `04_생성기/02` 로 영문 변환을 검토한다.

## 이미지 검토가 판정하는 것

| 항목 | 방식 |
|---|---|
| A1 태그 실재 | 태그사전 + 스타일태그 + 작가태그 대조 |
| A2 언더바 | `_` 포함 여부 |
| A3 NSFW | 사전의 `NSFW=TRUE` 467행과 대조 |
| B2 숫자 끝 | 닫는 `::` 앞이 숫자인데 공백이 없는 경우 |
| B4 `::` 짝 | 개수가 홀수인지 |

**A1 은 두 갈래로 나눠 보고한다.** 태그사전엔 없지만 Q·N 프리셋에서 쓰는 어휘
(`8k` · `dramatic contrast` 등 177개)는 정상으로 처리한다 — 태그사전이 2022년 danbooru 기준이라
퀄리티·조명 어휘가 아예 없기 때문이다. 어디에도 없는 것만 "확인 필요"로 올린다.

가중치 그룹 안의 쉼표(`3::a, b, c::`)는 최상위 구분자로 세지 않고, 그룹 안 개별 태그도 각각 검사한다.

## 챗봇 검토가 판정하는 것

| 항목 | 방식 |
|---|---|
| A1 형식 통일 | XML · Markdown · YAML · INI · 블록(`[ ]`) 중 몇 가지가 섞였는지 |
| A2 언어 통일 | 줄마다 주도 문자를 세어 한/영/중 비율 산출 |
| A3 OOC | `OOC` 문자열 |
| A4 유저 지칭 | `{{user}}` 횟수 + 유저·당신·그대 등 다른 표기 혼재 |
| A5 메타 헤더 | 플랫폼·언어·형식·글자수·토큰 항목 유무 |
| B 하네스 블록 | 9개 블록의 `[블록명]` 유무 |
| B ③ Trigger | `→` 개수 (5개 미만이면 경고) |
| 분량 | 글자수 · 한글 수 · 대략 토큰 추정 |

**C절 밀도는 판정하지 않는다.** 고도·고신호 최소 집합·로어북 이관은 판단이 필요해
터미널의 Claude 에게 맡긴다.

## 파일을 추가해도 코드를 고칠 필요 없다

서버의 디렉터리 목록을 훑어 `.md` · `.csv` 를 자동으로 찾는다.
`.git` · `dcgall` · `viewer` 는 제외한다. 데이터를 HTML에 박아넣지 않으므로
CSV에 행을 추가하면 새로고침만 하면 반영된다.

## 한계
- 디렉터리 목록을 제공하는 서버가 필요하다 (`python3 -m http.server` 는 제공한다)
- 마크다운 렌더러는 저장소 문서에 맞춘 최소 구현이다 (제목·표·코드·목록·인용·링크)
