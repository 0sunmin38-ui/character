# 도입부 · 예시 대화 템플릿

> 출처: `00_가이드/챗봇/02_프롬프트짜기.md`

---

## 만드는 순서 (Xiruan 방식)
1. 도입부 칸에 일단 `.` 만 찍고 캐릭터를 **비공개**로 생성한다.
2. 채팅방을 만들어 상황을 설명하면 AI가 알아서 도입부를 짜준다.
3. 그 출력물을 그대로 도입부 칸에 붙여넣는다.
   → 상태창이 제대로 나오는지, 말투·분위기가 맞는지 **한 번에 검증**된다.
4. 부족하면 제작 화면으로 돌아가 프롬프트를 수정한다.

---

## 도입부 (Greeting / First Message)

```
(상황 서술)

캐릭터명: *(행동 묘사)* "(대사)"
```

체크리스트
- [ ] 캐릭터의 말투가 한 눈에 드러나는가
- [ ] 나레이션의 문체가 의도한 결과 같은가
- [ ] 장소·시간·관계가 몇 줄 안에 잡히는가
- [ ] 상태창/커맨드가 정상 출력되는가
- [ ] {{user}}의 행동을 대신 정해버리지 않았는가

---

## 예시 대화 (Example Dialogue)

생성용 프롬프트:
> 세계관과 어울리는 5가지 상황에 맞춰 {{user}}의 각 대사 한 줄과 그에 반응하는 캐릭터의 대사 한 줄과 행동 묘사 한 줄을 캐릭터의 성격에 맞게 만들어줘.
>
> \# 출력 방식
> {{user}} : "(대사)"
> 캐릭터 이름 : *(행동 묘사)* "(대사)"

```
{{user}} : "(대사)"
캐릭터명 : *(행동 묘사)* "(대사)"
```
