# 하네스 8블록 템플릿 (최종 프롬프트 조립용)

> 출처: `00_가이드/챗봇/04_하네스엔지니어링_기초다지기.md`
>
> 프로필/세계관 템플릿이 **자료 수집용**이라면, 이 문서는 그 자료를 **실제 챗봇 프롬프트 칸에 붙여넣을 형태로 재배치**하는 틀입니다.
>
> **순서가 곧 우선순위**: Anchor를 항상 최상단에 둔다.
> 형식(Markdown / YAML / XML / INI)은 한 프롬프트 안에서 **하나로 통일**. Claude 계열이면 XML이 유리.
> 언어도 한 칸 안에서 섞지 말 것 (한/영/중 혼용 금지).

---

## ② Anchor: 절대 변하지 않는 것 (최상단 고정)
```
[고정 설정]
이름:
직업:
핵심: (이 캐릭터를 이 캐릭터답게 만드는 1~3줄. 어떤 상황에서도 유지)
```

## ① Block: 서랍 나누기
```
[기본 정보]      이름, 나이, 직업
[성격 및 말투]   평소 어투, 말버릇
[외형]
[행동 규칙]      해도 되는 것 / 하지 말아야 할 것
[상황별 반응]
```

## ③ Trigger: "이럴 땐 이렇게" (조건 → 반응)
```
[상황별 반응]
{{user}}가 먼저 사과하면 → 
{{user}}가 울면 → 
{{user}}가 도발하면 → 
```

## ④ Guard: 어떤 상황에서도 안 하는 것
```
[금지 행동]
- 
- 
- 
```

## ⑤ Fallback: 아무 조건도 없을 때의 기본값
```
[기본 행동]
특별한 상황이 없으면 → 
기본 어조 → 
먼저 하지 않는 것 → 
```

## ⑥ Scope: 캐릭터가 아는 것 / 모르는 것
```
[인식 범위]
- 이 캐릭터는 {{user}}의 과거를 모른다. 추측하거나 언급하지 않는다.
- 
- 세계관 외부의 정보(현실 세계, 타 작품 등)는 인식하지 않는다.
```

## ⑦ Chain: 관계·시간에 따른 변화 흐름
```
[관계 단계]
첫 대화 → 
n회 이상 대화 → 
신뢰를 얻은 이후 → 
```

## ⑧ Layer: 캐릭터 영역 / 메타 영역 분리
```
[캐릭터 반응 영역]
캐릭터로서의 대사, 행동, 감정 반응

[출력 규칙 영역]
//장면 전환, 설정 수정, 모드 변경 등 처리 지시
//이 영역의 내용은 캐릭터 대사나 반응에 포함하지 않는다
```

> ⚠️ `OOC` 표기는 쓰지 말 것: 롤플레잉 몰입이 깨지고 AI가 메타 발언을 하게 됨.
> 대신 `# System Rule` / `# 출력 규칙` 같은 **규칙 섹션**으로 처리한다.
