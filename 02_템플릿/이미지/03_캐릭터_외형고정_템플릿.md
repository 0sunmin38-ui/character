**여기는 "무엇을 정해야 하는가"만 있다. 태그 값은 `01_자료/이미지/1-태그사전.csv` 에서 찾는다.**

## 캐릭터명:

| 항목 | 값 | 어디서 찾나 |
|---|---|---|
| 인원·기본 | | `시트=태그인물` · `분류1=인원` |
| 피부 | | `시트=태그외모` · `분류1=피부` |
| 눈 색 | | `시트=태그외모` · `분류1=눈` |
| 눈 모양 | | `시트=태그외모` · `분류2=모양` |
| 속눈썹·눈매 디테일 | | `시트=태그외모` · `분류2=속눈썹` |
| 머리 색 | | `시트=태그외모` · `분류1=머리` `분류2=색` |
| 머리 길이 | | `분류2=길이` |
| 앞머리 | | `분류2=앞머리` |
| 뒷머리·헤어스타일 | | `분류1=머리` |
| 머리 위치 | | `분류2=위치` |
| 체형 | | `시트=태그체형` · `분류1=몸` |
| 가슴 | | `시트=태그체형` |
| 고정 액세서리 | | `시트=태그장신구` |

```bash
D=01_자료/이미지/1-태그사전.csv
awk -F, '$1=="태그외모" && $2=="머리"' $D     # 머리 관련 태그 전부
grep -i "눈매" $D                              # 한글명으로 검색
```

## 채우는 방법
1. 완성된 캐릭터 프로필/세계관을 txt로 저장
2. Nai 프롬프트 생성 Gem(`01_자료/이미지/0-참고링크.csv`)에 넣고:
> (캐릭터 이름)의 외형을 고정하기 위해 상세한 외형 태그를 만들어줘. 눈모양, 앞머리 모양, 뒷머리 모양, 머리색 등등 자세하게 만들어줘.
3. 나온 태그가 **사전에 실재하는지** 대조 → `05_검토/02_이미지프롬프트_검토표.md` A1
