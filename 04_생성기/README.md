# 04_생성기 — AI에게 시킬 메타 프롬프트

**생성은 Gemini Gems에서 한다** (링크: `01_자료/챗봇/0-참고링크.csv`).
여기 남은 건 Gem이 해주지 않는 것 — 이미 만든 자료를 **재배치·압축·추출**하는 변환기다.

| 파일 | 하는 일 | 결과가 가는 곳 |
|---|---|---|
| `01_챗봇_하네스_재배치기.md` | 자료 → 하네스 8블록 프롬프트 | `.../01_프롬프트.md` |
| `02_챗봇_토큰최적화_변환기.md` | 언어·형식 변환, 글자수 줄이기 | 위 파일 갱신 |
| `03_이미지_컨셉to태그_생성기.md` | Gem 없이 쓸 때의 26슬롯 주입 + 작가 태그 주의 | `03_프롬프트/이미지/` |
| `04_문체지침_추출기.md` | 앵커 작품 → `# 문체` 지시문 | `03_프롬프트/챗봇/모듈/문체지침/` |

프로필·세계관 채우기와 이미지 컨셉·외형 태그 생성은 Gem이 대신하므로 여기서 뺐다.
Gem 링크는 `01_자료/챗봇/0-참고링크.csv`(캐릭터·세계관) · `01_자료/이미지/0-참고링크.csv`(Nai 프롬프트).

## 공통 주의
- AI에게 다 맡기면 천편일률적인 캐릭터가 나온다. **러프 컨셉은 직접 짤 것**
- 빈칸은 미리 지우지 말고 남겨둔다 → 지우면 AI가 멋대로 채운다
- Gemini는 Pro 모델 권장 (무료면 사고 모델)
