# 04_생성기: AI에게 시킬 메타 프롬프트

**생성은 Gemini Gems에서 한다** (링크: `01_자료/챗봇/0-참고링크.csv`).
여기 남은 건 Gem이 해주지 않는 것: 이미 만든 자료를 **재배치·압축·추출**하는 변환기다.

| 파일 | 하는 일 | 결과가 가는 곳 |
|---|---|---|
| `01_챗봇_하네스_재배치기.md` | 자료 → 하네스 8블록 프롬프트 | `.../01_프롬프트.md` |
| `02_챗봇_토큰최적화_변환기.md` | 언어·형식 변환, 글자수 줄이기 | 위 파일 갱신 |
| `03_챗봇_문체지침_추출기.md` | 앵커 작품 → `# 문체` 지시문 | `03_프롬프트/챗봇/모듈/문체지침/` |
| `04_이미지_캐릭터외형고정_생성기.md` | **Gem 활용.** 프로필 → 외형 고정 태그 | 에셋 → 태그조합 → 외형 |
| `05_이미지_컨셉to태그_생성기.md` | **Gem 없이.** 26슬롯 주입 + 작가 태그 주의 | 에셋 → 태그조합 |

번호는 읽는 순서다. 챗봇 셋이 먼저, 이미지 둘이 뒤에 온다.
이미지 쪽은 **Gem 을 쓰는 쪽을 먼저** 둔다. Gem 이 있으면 그게 정공법이고,
`05` 는 Gem 을 못 쓸 때의 대체다.

프로필·세계관 채우기는 Gem이 대신하므로 여기서 뺐다.
Gem 링크는 `01_자료/챗봇/0-참고링크.csv`(캐릭터·세계관) · `01_자료/이미지/0-참고링크.csv`(Nai 프롬프트).

## 여기 두는 것 / 안 두는 것

**생성기에는 인풋과 프롬프트만 둔다.** 재료가 무엇인지, 어떤 지시문을 넣는지, 그 지시문을 쓸 때
주의할 것까지다. 받은 결과를 검토하거나 어디에 저장하는지는 다른 문서의 몫이다.

| 여기 | 다른 곳 |
|---|---|
| 재료(인풋) · 지시문 · 지시문 쓸 때 주의 | 결과 검토 → `05_검토/` |
| | 저장 위치·양식 → `03_프롬프트/` |
| | 넘칠 때 줄이는 순서 → `05_검토/01` C5 |

## 공통 주의
- AI에게 다 맡기면 천편일률적인 캐릭터가 나온다. **러프 컨셉은 직접 짤 것**
- 빈칸은 미리 지우지 말고 남겨둔다 → 지우면 AI가 멋대로 채운다
- Gemini는 Pro 모델 권장 (무료면 사고 모델)
