# 04_생성기: AI에게 시킬 메타 프롬프트

> **캐릭터(챗봇) 프롬프트는 여기 없다.** 별도 저장소 `luvheilcharacter` 로 떨어져 나갔다.
> 챗봇 생성기 셋(`01`~`03`)은 그쪽으로 옮겼다. 번호는 그대로 두었다.

| 파일 | 하는 일 | 결과가 가는 곳 |
|---|---|---|
| `04_이미지_캐릭터외형고정_생성기.md` | **Gem 활용.** 프로필 → 외형 고정 태그 | 에셋 → 태그조합 → 외형 |
| `05_이미지_컨셉to태그_생성기.md` | **Gem 없이.** 26슬롯 주입 + 작가 태그 주의 | 에셋 → 태그조합 |

**Gem 을 쓰는 쪽을 먼저** 둔다. Gem 이 있으면 그게 정공법이고, `05` 는 못 쓸 때의 대체다.
Gem 링크는 `01_자료/이미지/0-참고링크.csv`.

## 여기 두는 것 / 안 두는 것

**생성기에는 인풋과 프롬프트만 둔다.** 재료가 무엇인지, 어떤 지시문을 넣는지, 그 지시문을 쓸 때
주의할 것까지다. 받은 결과를 검토하거나 어디에 저장하는지는 다른 문서의 몫이다.

| 여기 | 다른 곳 |
|---|---|
| 재료(인풋) · 지시문 · 지시문 쓸 때 주의 | 결과 검토 → `05_검토/` |
| | 저장 위치·양식 → `03_프롬프트/` |
| | 넘칠 때 줄이는 순서 → `05_검토/02` |

## 공통 주의
- AI에게 다 맡기면 천편일률적인 캐릭터가 나온다. **러프 컨셉은 직접 짤 것**
- 빈칸은 미리 지우지 말고 남겨둔다 → 지우면 AI가 멋대로 채운다
- Gemini는 Pro 모델 권장 (무료면 사고 모델)

## 05_검토와의 관계
생성기의 지시문과 `05_검토/02` 의 판정 기준은 같은 것을 본다. 붙여넣기용이라
자족적이어야 해서 일부러 중복해 적어둔 것: **한쪽을 고치면 다른 쪽도 같이 고칠 것.**
