# 생성기: 프로필/세계관 → 하네스 8블록 재배치

프로필·세계관은 **자료**이고, 실제 프롬프트 칸에 넣을 것은 **하네스 구조로 재배치한 결과물**이다.

```
아래는 캐릭터 챗봇용 설정 자료다. 이걸 하네스 구조로 재배치해줘.

출력 순서 (이 순서를 반드시 지킬 것)
1. [고정 설정]: 어떤 상황에서도 변하지 않는 핵심 정체성. 3줄 이내.
2. [기본 정보]: 이름, 나이, 직업, 외형
3. [성격 및 말투]: 평소 어투, 말버릇, 어휘 특징
4. [상황별 반응]: "조건 → 반응" 형식으로 최소 5개
5. [금지 행동]: 어떤 상황에서도 하지 않는 것
6. [기본 행동]: 특별한 조건이 없을 때의 기본값 (어조, 답변 길이, 먼저 하지 않는 것)
7. [인식 범위]: 이 캐릭터가 아는 것 / 모르는 것
8. [관계 단계]: 관계 진전에 따른 행동 변화 흐름
9. [출력 규칙]: 처리 지시. 캐릭터 대사에 절대 포함되지 않는 영역

규칙
- 형식은 Markdown 하나로 통일. 다른 형식(YAML/XML)과 섞지 말 것.
- "OOC"라는 단어를 쓰지 말 것.
- 자료에 없는 설정을 새로 만들지 말 것.
- 사용자 지칭은 전부 {{user}} 로 통일.

--- 자료 ---
(프로필 + 세계관 붙여넣기)
```

> 형식을 XML/YAML로 뽑고 싶으면 위 "Markdown 하나로 통일" 부분만 바꿔서 지시.
> Claude 계열 LLM을 쓰는 플랫폼이면 XML이 인식률이 좋다.
