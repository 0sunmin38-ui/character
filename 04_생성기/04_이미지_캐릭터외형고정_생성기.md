# Gem 활용: 캐릭터 외형 생성 팁

챗봇 캐릭터와 **같은 얼굴을 매번 뽑기 위한** 외형 태그를 **Nai 프롬프트 생성 Gem** 으로 만든다 (위 카드).
결과는 에셋 → 태그조합 → **외형** 에 넣고 저장한다. 한 번 정하면 그 캐릭터를 그릴 때마다 쓴다.

재료: 완성된 캐릭터 프로필·세계관 (`02_템플릿/캐릭터/01,02` 로 채운 것)

---

## 지시문

프로필·세계관을 txt 로 저장해 **Nai 프롬프트 생성 Gem** 에 첨부하고 아래를 넣는다.

```
(캐릭터 이름)의 외형을 고정하기 위해 상세한 외형 태그를 만들어줘.
눈모양, 앞머리 모양, 뒷머리 모양, 머리색 등등 자세하게 만들어줘.
```

---

## 색은 반드시 명시한다

**비워두면 시드마다 흔들린다.** 머리색·눈색·의상색은 빠짐없이 적고,
보조 색까지 붙이는 편이 안전하다.

```
brown hair, ash brown hair
```
