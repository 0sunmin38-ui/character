### 자주 참조할 지점
- **하네스 8구조:** ①Block ②Anchor ③Trigger ④Guard ⑤Fallback ⑥Scope ⑦Chain ⑧Layer
- **증상 → 원인**
  - 중반부터 말투가 바뀜 → 초반 설정이 컨텍스트 밖으로 밀려남 (→ Anchor)
  - 설정을 추가할수록 다른 설정을 무시 → 우선순위 없는 텍스트 덩어리 (→ Block)
  - 특정 상황에서 설정과 다르게 반응 → 조건부 행동 미지정 (→ Trigger/Fallback)
  - 친해질수록 냉담함 같은 특성을 잃음 → 관계 변화 미정의 (→ Chain/Guard)
- **OOC 사용 금지** — 몰입이 깨지고 메타 발언을 학습함. `# System Rule` / `# 출력 규칙` 으로 대체.
