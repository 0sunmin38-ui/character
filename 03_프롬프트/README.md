# 03_프롬프트: 최종 산출물 ★

완성되어 **그대로 복붙해서 쓸 수 있는** 프롬프트만 여기 둔다. 미완성은 `99_작업중/`.

## 분류 기준

> **캐릭터(챗봇) 프롬프트는 여기 없다.** 별도 저장소 `luvheilcharacter` 로 떨어져 나갔다.

```
03_프롬프트/
└── 이미지/
    ├── 작가태그/             그림체 (캐릭터와 무관, 재사용)
    ├── 스타일프리셋/          퀄리티·부정 (캐릭터와 무관, 재사용)
    ├── 캐릭터/               캐릭터별 외형 고정 (재사용)
    └── 장면/                 1회성 상황·컨셉
```

> **판단 기준 한 줄:** 다른 캐릭터에도 쓸 수 있으면 `프리셋/`, 이 캐릭터 전용이면 `캐릭터/`.

## 파일 머리말 규칙
모든 프롬프트 파일 맨 위에 다음을 적는다.
```
플랫폼:            (로판AI / 루모 / 케이브덕 / 티팟 / …)
언어:              (한국어 / 영어)
형식:              (Markdown / YAML / XML)
글자수 또는 토큰:    (현재 / 제한)
최종 수정:
```

## 챗봇 쪽과 이름 맞추기

같은 캐릭터의 이미지 파일명은 `luvheilcharacter` 저장소의
`03_프롬프트/캐릭터/<캐릭터명>/` 폴더명과 **같게** 맞춘다.
→ `03_프롬프트/이미지/캐릭터/<캐릭터명>.md`
