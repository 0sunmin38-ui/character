# 03_프롬프트: 최종 산출물 ★

완성되어 **그대로 복붙해서 쓸 수 있는** 프롬프트만 여기 둔다. 미완성은 `99_작업중/`.

## 분류 기준

```
03_프롬프트/
├── 챗봇/
│   ├── 캐릭터/<캐릭터명>/     한 캐릭터에만 해당하는 것
│   └── 모듈/                여러 캐릭터가 공유하는 것
└── 이미지/
    ├── 작가태그/             그림체 (캐릭터와 무관, 재사용)
    ├── 스타일프리셋/          퀄리티·부정 (캐릭터와 무관, 재사용)
    ├── 캐릭터/               캐릭터별 외형 고정 (재사용)
    └── 장면/                 1회성 상황·컨셉
```

> **판단 기준 한 줄:** 다른 캐릭터에도 쓸 수 있으면 `모듈/`·`프리셋/`, 이 캐릭터 전용이면 `캐릭터/`.

## 파일 머리말 규칙
모든 프롬프트 파일 맨 위에 다음을 적는다.
```
플랫폼:            (로판AI / 루모 / 케이브덕 / 티팟 / …)
언어:              (한국어 / 영어)
형식:              (Markdown / YAML / XML)
글자수 또는 토큰:    (현재 / 제한)
최종 수정:
```

## 캐릭터 폴더 표준 구성 (챗봇)
```
03_프롬프트/챗봇/캐릭터/<캐릭터명>/
├── 00_메모.md          플랫폼·글자수·수정 이력·미해결 이슈
├── 01_프롬프트.md       ★ 메인 입력 칸에 들어가는 본문 (하네스 8블록)
├── 02_도입부.md         첫 대사
├── 03_예시대화.md
├── 04_로어북.md

```
