# 캐릭터별 외형 고정 태그

파일 1개 = 캐릭터 1명. 파일명은 `03_프롬프트/챗봇/캐릭터/` 의 폴더명과 **동일하게**.

양식: `02_템플릿/이미지/03_캐릭터_외형고정_템플릿.md`
생성: Gem(Nai 프롬프트 생성)에 챗봇 프로필을 첨부해서 뽑는다
검토: `05_검토/02_이미지프롬프트_검토표.md`

한 캐릭터에 복장 변형이 여러 개면 한 파일 안에 섹션으로 나눈다.
```
## 고정 블록 (얼굴·머리·체형)
## 변형 A — 교복
## 변형 B — 사복
```
